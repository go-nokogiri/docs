# nokogiri

XML/HTML parser + XPath/CSS queries + libxml2-faithful serialization (Nokogiri-class).

## Install

```bash
go get github.com/go-nokogiri/nokogiri
```

Requires Go 1.26.4 or newer. `CGO_ENABLED=0`.
